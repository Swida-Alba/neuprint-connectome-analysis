# Interactive Network Visualization - Draggable Nodes Guide

## Overview
The network visualizations generated by `FindPath()` and `FindAllPath()` now include **draggable nodes** functionality, allowing you to manually adjust the layout for better clarity and publication-quality figures.

## Features

### 🎯 Interactive Controls

1. **Node Dragging** (Toggle Mode)
   - Click the **"Toggle Node Drag Mode"** button (top-right, green button)
   - When ON (red button): Click and drag any node to reposition it
   - When OFF (green button): Standard pan/zoom mode

2. **Pan & Zoom**
   - **Scroll** to zoom in/out
   - **Click and drag** background to pan (when drag mode is OFF)
   - **Double-click** to reset view to original

3. **Selection Tools**
   - **Box Select**: Click icon in toolbar to select multiple nodes
   - **Lasso Select**: Draw a custom selection shape

4. **Edge Information**
   - **Hover** over edges to see:
     - Source → Target neuron names
     - Connection weight (synapse count)
     - Traversal probability

5. **Node Information**
   - **Hover** over nodes to see:
     - Neuron name/ID
     - Layer assignment
     - Node type (source/target/intermediate)
     - In-degree and out-degree
     - Drag instruction

## How to Use

### Basic Workflow

1. **Open the HTML file** in your web browser
   - Files are typically named:
     - `visualization/Network_<run>.html` (type level)
     - `bodyId_visualization/Network_<run>.html` (bodyId level)
     - `network_early/Network_<run>.html` (early type-level preview)
     - `network_early_bodyId/Network_<run>.html` (early bodyId preview)

   `<run>` is the run-folder name. Complete Paths and Shortest Paths use the
   same naming contract; the containing folder identifies the level.

2. **Enable drag mode**
   - Click the green **"Toggle Node Drag Mode (OFF)"** button
   - Button turns red and shows **"Toggle Node Drag Mode (ON)"**

3. **Reposition nodes**
   - Click on any node
   - Hold and drag to desired position
   - Release to drop

4. **Disable drag mode** when done arranging
   - Click the red button to return to green (OFF)
   - Now you can pan/zoom normally

5. **Export your layout**
   - Click the camera icon in the toolbar
   - Download as PNG with your custom layout

### Advanced Tips

#### For Complex Networks
```
1. Start with 'layered' network_layout parameter (shows clear hierarchy)
2. Enable drag mode
3. Manually spread out crowded nodes
4. Group related neurons visually
5. Create clear pathways for important connections
6. Export final layout
```

#### For Publication Figures
```
1. Use 'distributed' layout for initial spread
2. Enable drag mode
3. Arrange key neurons symmetrically
4. Align important pathways horizontally or vertically
5. Ensure no overlapping labels
6. Zoom to focus area if needed
7. Export high-resolution PNG (camera icon)
```

#### For Presentations
```
1. Arrange network to tell a story (left-to-right flow)
2. Position source neurons on left
3. Position target neurons on right
4. Create clear visual pathways
5. Use zoom to focus on specific regions
6. Export at 2x scale for sharp images
```

## Technical Details

### How It Works

**Node Dragging Implementation:**
1. Custom JavaScript injected into HTML file
2. Toggle button switches between pan mode and drag mode
3. Mouse events track node positions
4. Plotly.restyle() updates node coordinates in real-time
5. Connected edges automatically follow dragged nodes

**Edge Updates:**
- When you drag a node, all connected edges automatically adjust
- Arrow annotations update to maintain proper direction
- Edge hover information remains intact

### Layout Preservation

**Current Limitation:**
- Layout changes are **not automatically saved** to disk
- To preserve a custom layout:
  1. Export as PNG using camera icon
  2. Or take a screenshot
  3. Or manually save positions (see Advanced section below)

**Future Enhancement:**
- Could add "Save Layout" button to export node positions as JSON
- Could reload custom layouts in subsequent sessions

### Browser Compatibility

**Recommended Browsers:**

- ✅ Edge (good performance)
- ⚠️ Safari (works but slower)

**Requirements:**
- JavaScript enabled
- Modern browser (ES6+ support)
- Minimum screen resolution: 1024x768

## Example Use Cases

### Case 1: Untangling Overlapping Nodes

**Problem:**
```
Initial layout:    After dragging:
  A──B               A────C
  │  │               │    │
  C──D               B────D

Nodes A,B,C,D        Clear spacing,
overlap              no overlaps
```

**Solution:**
1. Toggle drag mode ON
2. Drag nodes away from each other
3. Create visual separation
4. Toggle drag mode OFF

### Case 2: Creating Hierarchical Layout

**Problem:**
```
Initial (distributed):  After arranging:

  B                        A
 ╱│╲                       │
A C D                     ╱│╲
    │                    B C D
    E                        │
                            E
```

**Solution:**
1. Identify hierarchy layers
2. Drag nodes to align vertically by layer
3. Space horizontally within layers
4. Create clear top-to-bottom flow

### Case 3: Emphasizing Key Pathways

**Problem:**
Multiple paths exist but want to highlight main pathway.

**Solution:**
1. Identify critical path nodes
2. Arrange them in a straight line (left-to-right or top-to-bottom)
3. Move secondary path nodes to periphery
4. Create visual emphasis through positioning

## Keyboard Shortcuts (Browser Standard)

- **Ctrl/Cmd + 0**: Reset zoom to 100%
- **Ctrl/Cmd + Plus**: Zoom in
- **Ctrl/Cmd + Minus**: Zoom out
- **Ctrl/Cmd + S**: Save page (saves HTML, not layout changes)

## Troubleshooting

### Nodes Won't Drag

**Check:**
1. Is drag mode enabled? (Button should be RED)
2. Are you clicking directly on a node (not edge)?
3. Try refreshing the page
4. Check browser console for JavaScript errors

### Edges Don't Follow Nodes

**Possible causes:**
1. Browser performance issue (too many edges)
2. Try with smaller network first
3. Edge updates are approximate (may need manual refresh)

### Button Not Visible

**Solutions:**
1. Check if button is behind other elements
2. Try zooming out (Ctrl/Cmd + Minus)
3. Resize browser window
4. Check browser console for errors

### Performance Issues

**For large networks (>1000 nodes):**
1. Drag mode may be slow
2. Consider using 'layered' layout instead of 'distributed'
3. Filter to smaller subset of neurons
4. Use bodyId network only for focused analysis

## Advanced: Programmatic Layout Control

### Saving Custom Layouts

If you want to programmatically save and restore layouts, you can modify the code:

```python
# In _plot_interactive_network method, after creating pos:

# Save initial positions
import json
layout_file = filename.replace('.html', '_layout.json')
with open(layout_file, 'w') as f:
    layout_data = {str(node): {'x': float(x), 'y': float(y)} 
                   for node, (x, y) in pos.items()}
    json.dump(layout_data, f, indent=2)
```

### Loading Custom Layouts

```python
# Before creating fig, load saved positions:
layout_file = filename.replace('.html', '_layout.json')
if os.path.exists(layout_file):
    with open(layout_file, 'r') as f:
        saved_pos = json.load(f)
    # Convert back to pos dictionary
    pos = {eval(k): (v['x'], v['y']) for k, v in saved_pos.items()}
```
